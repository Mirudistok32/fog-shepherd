# Пастух в тумане

Пиксельная игра на canvas для портфолио: утро, туман, собака загоняет разбредшееся стадо в
загон до рассвета. Интерфейс, документация и ответы — по-русски.

Общие принципы и имена команд — `../agent-base/docs/` (principles, conventions). Здесь —
только то, что отличает этот проект. Стек и каркас взяты копией из `../pigeon-post`
(общего кода нет: проекты не зависят друг от друга).

## Стек и запуск

- Vite + TypeScript без фреймворка, рисование — `canvas` 2D, звук — Web Audio; данные
  пользователя — `localStorage` (`fog-shepherd:*`), бэкенда нет.
- Открыть: `npm run build`, затем двойной клик по `dist/index.html` (всё вложено в один файл,
  `scripts/postbuild.mjs`). Разработка — `npm run dev`.
- Публикация: GitHub Pages на пуш в `main` или `master` (`.github/workflows/pages.yml`) и Vercel
  (`vercel.json`); шаги — README → «Публикация». В `index.html` адрес сайта — только
  `__SITE_URL__`, подставляет сборка (`scripts/siteUrl.ts`). Абсолютные адреса не вписывать: имя
  репозитория и домен могут поменяться.
- Параметры адреса: `?autopilot` — уровень ведёт бот; `?seed=текст` — своя раскладка (все
  уровни открыты); `?level=N` — открыть уровень N, даже закрытый; `?playtest` — журнал
  попыток и кнопка отчёта (`docs/playtest.md`). С `?autopilot` и `?seed` игра ничего не пишет в
  сохранение. Задание дня — обычный `?seed=day-ГГГГ-ММ-ДД&level=N` (`domain/daily.ts`).

## Правила

- Слои (`docs/architecture.md`): `domain/` — чистые функции; время, ввод и случайность
  (состояние генератора в забеге) приходят аргументами, никакого `Math.random`/`Date`/DOM;
  границы проверяет `tests/unit/architecture.test.ts`.
- Симуляция шагает строго по `STEP = 1/120` с: поведение одинаково на 60, 120 и 144 Гц
  (`tests/unit/game.test.ts`). Длительность кадра в домен не передаётся.
- Уровни кампании — из сида `level-N:v1` (`levelSeed`). Изменение генератора меняет раскладки
  и обесценивает рекорды: новая версия сида — осознанное решение в `docs/decisions.md`.
- Любое изменение физики, поведения стада, генератора или бота — `npm run balance`: бот
  загоняет всё стадо на каждом уровне без потерь, в норматив ★★★ и не дольше 70 % ночи;
  бот-новичок, не видящий сквозь туман, берёт хотя бы ★ в каждой попытке, медиана — не больше
  90 % ночи; таблицы «Баланс» в README обновить. Время до рассвета и нормативы — таблица
  `CAMPAIGN` в `src/domain/level.ts` (как подобраны — комментарий там). Менять их по отчётам
  живых игроков — `docs/playtest.md`.
- Туман не обманывать: всё, что подсказывает игроку, где овцы (мини-карта, подсказки), берёт
  видимость из `sheepVisible` в `domain/fog.ts`. Анимация и погода — только в
  `presentation/`, на симуляцию не влияют.
- Тексты экранов — в `index.html` (видны без JS), подписи на лету — `src/content/texts.ts`.
- id ачивок и поля сохранения — ключи в `localStorage`: не переименовывать без миграции
  (`docs/save-format.md`).

## Проверки

- `npm run check` — типы, линтер, формат, юнит-тесты: правила стаи, столкновения (углы,
  высокая скорость, давка), генератор на 520 сидах, туман, правила забега, бот и новичок на
  всех уровнях, подсказки, задание дня, журнал плейтеста, фон, счёт, ачивки, сохранение,
  контраст токенов, границы слоёв.
- `npm run check:full` — + сборка и e2e по `file://` и по http в корне сайта и в подпапке
  (ноутбук и телефон 390 px): мышь, тап, клавиатура, свист, мини-карта, подсказки, задание дня и «поделиться», плейтест, ветер в
  игре, тестовый сид, пауза, рестарт, сохранение, копия, reduced-motion, замер кадра при
  процессоре вчетверо медленнее.
- `npm run balance` — бот на всех уровнях и 24 случайных раскладках, бот-новичок на всех
  уровнях, печатает таблицы.
- Визуально: `npm run shots [фильтр]` после `build` — экраны × 1280/390/844×390 ×
  тёмная/светлая, игра в тумане по сезонам, загон, подсказка, погоня, задание дня, рассвет,
  итог; ошибки консоли и прокрутка вбок.
- Превью ссылки: `npm run og` → `public/og.png`.

## Нельзя

- Менять и удалять ключи `localStorage` и id ачивок без миграции.
- Глушить правила линтера, удалять тесты, снижать пороги ради зелёного гейта.
- Подгонять тест бота или физики под сломанное поведение: чинить стадо, генератор или бота.
