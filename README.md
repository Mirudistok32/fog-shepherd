# Пастух в тумане

Пиксельная игра в браузере. Утро, туман, стадо разбрелось по лугу. Вы — собака-пастух:
соберите всех овец в загон с фонарём, пока не взошло солнце. Видно только вокруг собаки и у
загона; овец вдалеке выдают силуэты и блеяние, а отбившиеся бредут к лесу и теряются в нём.

Двенадцать уровней кампании и тренировка; весна, лето, осень и зима. С каждым уровнем больше
овец, гуще туман и меньше времени на овцу. Овцы ведут себя как стая: держатся вместе, бегут
от собаки, пасутся, когда спокойны. Звёзды за уровень, рекорды, девять ачивок, резервная копия
в JSON. На первых уровнях подсказывает, что делать; задание дня — новая раскладка, одна на
всех, с итогом и ссылкой для друга. Погода по сезонам, пыль из-под лап, ветер и птицы на
рассвете. Всё нарисовано кодом на `canvas`, звуки синтезируются Web Audio — ни одного файла.

## Как открыть

```bash
npm install
npm run build
```

Затем откройте **`dist/index.html`** двойным кликом — сервер не нужен. Этот же файл
выкладывается на любой статический хостинг. Как опубликовать — [ниже](#публикация).

Параметры адреса: `?autopilot` — уровень ведёт бот, `?seed=любой-текст` — своя раскладка,
`?level=N` — сразу уровень N, `?playtest` — записывать попытки для отчёта
([docs/playtest.md](docs/playtest.md)). С ботом и своей раскладкой игра ничего не сохраняет.
Задание дня — это `?seed=day-ГГГГ-ММ-ДД&level=N`: кнопка в меню ведёт на такую ссылку.

## Публикация

Нужен Node 24 или новее. Сайт собирается в `dist/`: `index.html` со всем внутри и `og.png`.
Пути относительные, поэтому игра работает и в корне домена, и в подпапке.

**GitHub Pages.** Уже настроено в `.github/workflows/pages.yml`: пуш в `main` или `master` →
проверки → сборка → публикация. Один раз в репозитории: Settings → Pages → Build and deployment
→ Source: **GitHub Actions**. Если проверки не прошли, сайт не обновится.

**Vercel.** Add New → Project → выбрать этот репозиторий → Deploy. Настройки берутся из
`vercel.json`, переменные окружения не нужны.

**Адрес сайта** в canonical и превью ссылки подставляется при сборке сам: на Pages — адрес
репозитория или свой домен, на Vercel — рабочий домен, на компьютере — `homepage` из
`package.json`. Каждая площадка указывает на себя. Чтобы canonical у обеих вёл на один адрес,
задайте в Vercel переменную `SITE_URL` (Settings → Environment Variables) с адресом на Pages.

Сохранения привязаны к адресу: у Pages и Vercel они разные, перенести можно резервной копией.

## Управление

| Что сделать | Что будет |
| --- | --- |
| Вести мышью по лугу | собака бежит за курсором; ближе к собаке — медленнее |
| Коснуться пальцем | собака бежит к пальцу и добегает до места, где его убрали |
| Стрелки или WASD | собака бежит в эту сторону, пока клавиша нажата |
| Пробел или «Свист» | овцы рядом сбиваются в кучу и успокаиваются; снова — через 4 с |
| Коснуться мини-карты (узкий экран) | собака бежит в эту точку луга |

Пауза — Esc, P или кнопка ⏸; звук — M или кнопка в меню. Ушли со вкладки — игра на паузе.

## Правила

- Овцы уходят от собаки: заходите сзади и гоните к воротам. Бегущая собака пугает сильнее
  идущей — налетите на стадо, и оно разбежится; потом соберётся снова.
- Через заборы, кусты и ручей овцы не ходят — только в обход и по мостику. Собака
  перепрыгивает заборы и переплывает ручей.
- Отбившаяся овца бредёт к лесу. Ушла в лес — несколько секунд, чтобы её вернуть.
- ★ — две трети стада в загоне, ★★ — всё стадо, ★★★ — всё стадо быстрее норматива. Звезда
  открывает следующий уровень.

### Бот-новичок

Обычный бот видит сквозь туман. Бот-новичок (`src/domain/novice.ts`) знает только то, что
видно на экране: овец в пределах видимости и там, где они в последний раз заблеяли. Он обходит
луг, если никого не знает, реагирует с задержкой, ошибается в прицеле, отвлекается и срывается

## Команды

```bash
npm run dev            # разработка
npm run build          # проверка типов, сборка в один dist/index.html
npm run check          # типы, линтер, формат, юнит-тесты (с ботом на всех уровнях)
npm run check:full     # check + сборка и e2e (Playwright по file:// и http, ноутбук и 390 px)
npm run balance        # бот и бот-новичок на всех уровнях — таблицы баланса
npm run shots          # снимки всех экранов в .screenshots/
npm run og             # картинка превью public/og.png
npm run format         # Prettier
```

## Стек

- **Vite** + **TypeScript** без фреймворка, `canvas` 2D, Web Audio
- **Vitest** (стая, столкновения, генератор на 520 сидах, туман, правила, бот и новичок,
  подсказки, задание дня, журнал плейтеста, фон, сохранение, контраст, границы слоёв),
  **Playwright** (e2e по `file://`, мини-карта на телефоне, замер кадра)
- Шрифты Ubuntu, Roboto, Tektur — в репозитории, вложены в сборку

## Где что лежит

```

                   уровней, путь до загона, стая, шаг симуляции, туман, бот и новичок,

  application/     игра без DOM: экраны, фиксированный шаг, ввод, демо в меню; порты
```

## Ограничения

- Рекорды и ачивки хранятся в `localStorage` этого браузера; у каждого сайта и у файла с диска
  они разные. Перенос — «Ачивки → Резервная копия»: копия объединяется с текущими данными.
- Если игра открыта в двух вкладках, побеждает последняя записанная.
- На телефоне вертикально на экране половина луга, камера едет за собакой; весь луг — на
  мини-карте под ним, повёрнутым — на экране целиком.
- Задание дня не хранит итог: он не идёт в рекорды, а общей таблицы результатов нет, потому что
  нет бэкенда. Сравнивать результаты можно, отправив друг другу итог со ссылкой.
