# Принятые решения

| Решение | Причина |
| --- | --- |
| **Стек и каркас — копией из pigeon-post** (30.10.2026) | Требование ТЗ: Vite + TS + canvas, сборка в один файл, те же проверки; общего кода нет, проекты независимы. |
| **Мир один на все уровни: 384×216, сверху деревня, по краям лес** | Уровни сравнимы, бот и тесты работают в одних координатах. На узком экране холст не уже 192 точек, камера едет за собакой, у края — стрелка к загону. |
| **Собака перепрыгивает заборы и кусты, переплывает ручей (медленнее)** | Препятствия — для овец; игроку не нужно обводить собаку, боту — искать ей путь. Заходить за стадо — главное умение, его не прячем за стенами. |
| **Поле расстояний до загона (Дейкстра по клеткам)** | Одно и то же поле доказывает достижимость загона в тесте генератора, задаёт боту направление и помогает овцам у ворот и мостика. |
| **Гонимое стадо «помнит дорогу домой»** (`HOMING = 0,25`) | Без этого большое стадо толпится у мостика шириной в две овцы; бот на 12-м уровне не укладывался в ночь. Сила мала: собака по-прежнему решает, куда идти. |
| **Скольжение вдоль стены с решением на полсекунды и рывок из угла** | Тест «угол Г» показал дрожь: скольжение уводило овцу из угла, бегство возвращало. Мгновенный выбор стороны без памяти и есть дрожь. |
| **Спокойная овца у самых ворот заходит в загон сама** | С клавиатуры легко пробежать сквозь стадо; овцы отскакивали к воротам и стояли у входа. Это подсказка, а не автопилот: довести стадо до ворот всё равно надо. |
| **Под густым туманом овца не рисуется, вблизи — только силуэт** | Белые овцы просвечивали сквозь туман пятнами, и всё стадо было видно с первой секунды. ТЗ: вдалеке — силуэты и блеяние. |
| **Свет фонаря закрывает весь загон** | Загон должен быть виден всегда: это цель, а не загадка. |
| **«Меньше времени» — меньше времени на овцу и меньше запаса** | Время до рассвета — примерное время бота (25 с + 3 с на овцу) × запас от 3 до 1,55; на овцу — с 22 с до 5,6 с. Абсолютное время растёт со стадом: 40 овец в густом тумане за 2 минуты не загнать и боту. |
| **Звёзды: ⅔ стада, всё стадо, всё стадо быстрее норматива** | Понятно без таблицы; норматив = время бота на этом уровне × 1,5, три звезды достижимы (проверяет тест бота). |
| **Уровни из сида `level-N:v1`, а не случайные** | Рекорды сравнимы, бот в тесте проходит ровно те уровни, что видит игрок. `?seed=` — для проверок и показа. |
| **Фиксированный шаг 1/120 с, случайность — в состоянии забега** | Поведение не зависит от частоты экрана; один ввод — один забег (тесты на 60/120/144 Гц). |
| **`?autopilot` и `?seed` ничего не пишут в сохранение** | Режимы для e2e, скриншотов и показа; ачивки за бота были бы нечестными. |
| **Пауза при уходе со вкладки** | Стадо не должно разбежаться, пока никто не смотрит. |
| **Сохранение пишется в конце уровня** | Незавершённый уровень ничего не меняет в рекордах. |
| **Импорт копии только объединяет** | Рекорды и ачивки только растут; повторный импорт ничего не меняет. |
| **Мини-карта вместо отдаления камеры на вертикальном телефоне** (30.10.2026) | Весь луг в 390 px — это 1 точка мира на CSS-пиксель: овцы и собака слишком мелкие для пальца и глаза. А над и под лугом всё равно пусто. Карта показывает весь луг и не отнимает масштаб у основной картинки. |
| **Мини-карта не видит сквозь туман** | Иначе она обесценила бы туман и дала бы телефону преимущество. Овцы — только по `sheepVisible`, остальное — круги блеяния, как на большом экране. Касание карты посылает собаку: иначе из-за края экрана не зайти за стадо. |
| **Задание дня — обычный `?seed=` без записи в сохранение** | Ссылка работает у всех и везде, код режимов не растёт. Запись итога потребовала бы менять схему сохранения ради рекорда, который нельзя честно сравнить без бэкенда; вместо этого итог копируется и отправляется другу. |
| **Подсказки — по ситуации и только пока на уровне нет звезды** | Текст заранее никто не читает, а совет в момент ошибки запоминается. Уровень, пройденный хотя бы на звезду, больше не подсказывает; поле в сохранении не нужно. |
| **Бот-новичок вместо правки `CAMPAIGN` на глаз** | Обычный бот видит сквозь туман и ничего не говорит о человеке. Новичок показал: ночи хватает, запас меньше всего на уровнях 7–11, с 8-го он обычно теряет овцу. Таблица `CAMPAIGN` не менялась: параметры модели не откалиброваны, менять цифры надо по данным людей (`docs/playtest.md`). |
| **Журнал плейтеста — по `?playtest`, отдельным ключом, отчёт копируется вручную** | Бэкенда нет и не нужен; обычный игрок не платит за это ничем и ничего о нём не собирается. Брошенный уровень тоже пишется: это сильный сигнал о трудности. |
| **Фон и анимация не трогают симуляцию** | Шаг и раскладки те же: таблица бота не изменилась ни на секунду, рекорды и сид `level-N:v1` остаются в силе. |
| **Адрес сайта подставляется при сборке, а не вписан в `index.html`** (30.10.2026) | Две площадки, а превью ссылки требует абсолютного адреса: вписанный адрес сломал бы картинку превью на второй площадке или при смене имени репозитория. |
| **Pages и Vercel указывают каждая на себя, без общего canonical** | Так превью работает сразу и ничего не зависит от второй площадки. Для игры из портфолио дубль в поиске не страшен; общий адрес включается одной переменной `SITE_URL`. |
