# Формат сохранения

Ключ `fog-shepherd:save` (`localStorage`), JSON:

```json
{
  "schemaVersion": 1,
  "sound": true,
  "theme": "system",
  "level": 3,
  "levels": {
    "0": { "stars": 3, "saved": 3, "time": 6.2 },
    "1": { "stars": 2, "saved": 6, "time": 48.5 },
    "2": { "stars": 1, "saved": 6, "time": null }
  },
  "achievements": { "first-flock": "2026-10-30T12:00:00.000Z" },
  "stats": { "runs": 7, "flocks": 3, "penned": 31, "lost": 2, "whistles": 12, "seasons": ["spring"] }
}
```

- `theme`: `system | light | dark`; `level` — последний выбранный уровень (0 — тренировка).
- `levels[номер]` — лучшее на уровне: звёзды (0–3), больше всего овец в загоне за игру,
  лучшее время, когда в загоне всё стадо (`null` — такого не было). Могут быть из разных игр.
  Следующий уровень открыт, если на предыдущем есть звезда; тренировка и первый — всегда.
- `achievements` — id → дата открытия. id: `first-flock`, `whole-flock`, `quiet`, `early`,
  `rescuer`, `big-flock`, `seasons`, `hundred`, `gold`. Незнакомые id и уровни при чтении
  пропускаются (копия из версии новее не ломает старую).
- `stats.seasons` — времена года, в которые пройден уровень кампании (для «Круглого года»).
- Не прочиталось (обрывок, не JSON, не та форма, чужая версия) — данные откладываются в
  `fog-shepherd:save-corrupt`, игра начинает с чистого листа и сообщает об этом в меню.
  Хранилище недоступно — игра работает в памяти и предлагает скачать копию.

## Журнал плейтеста

Ключ `fog-shepherd:playtest`, только в режиме `?playtest` (`docs/playtest.md`): JSON-массив
попыток, не больше 300, старые вытесняются:

```json
[{ "level": 2, "seed": null, "stars": 2, "saved": 8, "total": 8, "lost": 0, "time": 70.5, "limit": 140, "par": 40, "whistles": 1, "quit": false, "dawn": false, "controls": "pointer" }]
```

`controls`: `pointer | keys | none`. `quit` — начал и бросил. Не прочиталось — журнал
начинается заново. В сохранение и резервную копию не входит.

## Резервная копия

`fog-shepherd-backup-ГГГГ-ММ-ДД.json`:

```json
{ "format": "fog-shepherd-backup", "schemaVersion": 1, "exportedAt": "…", "appVersion": "0.1.0", "data": { … } }
```

Импорт проверяет формат, версию (новее — отказ), размер (до 200 КБ) и поля, затем
**объединяет**: звёзды и овцы — максимум, время — минимум, ачивки — все с самой ранней
датой, итоги — большие, настройки — текущие.

## Миграции
